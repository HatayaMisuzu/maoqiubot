## 验证边界与本机依赖

真实 Hermes 验证使用仅含合成凭据的本机模型服务，未消耗云模型额度，也未验证实际云供应商、真实模型质量或真实工具执行。模型切换权限、工具授权和取消的行为由协议 fixture 覆盖。Hermes 自己的模型目录网络访问会影响冷启动；验收脚本使用隔离配置和本机目录响应，未修改官方 Hermes 源码。

本机 PATH 中已有的 Python 3.13 `hermes.exe` 执行 `--version` 实际报 `ModuleNotFoundError: No module named 'hermes_cli'`，不能作为可用入口。验证使用 TEMP 中隔离安装的官方运行时；未将临时路径或测试模型配置写入日常工作台。日常使用前仍需修复官方 Hermes 安装、配置其模型供应方，再在「Agent 设置」选择有效的官方启动器。

连接测试只验证 ACP 握手。Hermes 会从原生目录隐藏没有消息的空会话，预读模型后尚未发言的话题在连接器重启后需要新建，此限制已在接入说明中列明。
